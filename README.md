# 🚑 急診報馬仔 | 🐸全台醫院塞車雷達

本專案是一款專為台灣民眾打造的「全台急診即時戰情面板」。透過自動化數據監控與分流指南，旨在打破醫療資訊不透明，讓真正有緊急需求的患者與家屬能在關鍵時刻掌握重度急診量能，避免耗費就醫的黃金時間。

* **數據來源**：[衛生福利部中央健康保險署｜重度級急救責任醫院急診即時訊息](https://info.nhi.gov.tw/INAE4000/INAE4001S01)
* **專案起源**：起因於台中市立法委員羅廷瑋「喬病房」醫療平權爭議，促使本專案誕生。我們期盼透過科技透明化，將尋求在地管道協助的急迫需求，轉化為人人都可即時查閱的醫療數據雷達，減少走冤枉路的遺憾。
* **未來展望**：我們期盼藉由數據透明化，引導台灣民眾落實「醫療分級」的就醫習慣。透過清楚的量能警示，減少輕症患者盲目湧入重度級大醫院的現象，讓珍貴的緊急醫療資源能真正留給最需要的人。

## 🛠️ 專案技術架構 (Tech Stack)

本專案採用**前後端分離**架構，後端負責高頻率全自動資料調度，前端負責極致輕量的戰情化動態渲染，確保資安金鑰不外洩且網站接近秒開。

### ⚙️ 後端自動化爬蟲 (Backend & Automation)
* **核心語言**：`Python 3.13`
* **動態網頁動態解析**：`Playwright (Chromium)` —— 用於模擬網頁行為，突破傳統靜態爬蟲無法讀取衛福部動態渲染元件的限制。
* **資料庫同步**：`gspread` & `google-auth` —— 自動化將清洗後的資料寫入 Google Sheets 雲端，作為前端的唯讀資料緩存區（Data Cache）。
* **環境部署**：Linux (Debian 虛擬機) 搭配 `cron` 排程，定時於「避開整點」的離峰時間點高速運轉。

### 🎨 前端即時戰情板與地圖視覺化 (Frontend)
* **託管平台**：`GitHub Pages` —— 免費、高可用性的靜態網頁託管解決方案。
* **樣式框架**：`Tailwind CSS` —— 提供流暢的響應式設計（RWD），完美相容手機與 iMac 螢幕，並實作呼吸燈警戒動畫。
* **動態資料解析**：`PapaParse (JavaScript)` —— 輕量級 CSV 解析器，讓瀏覽器直接讀取 Google Sheets 發布的 CSV，免去架設後端 API 伺服器的成本。
* **地理資訊渲染**：`Leaflet.js` —— 開源互動式地圖函式庫，免金鑰、零成本在網頁中渲染台灣地圖，並根據醫院經緯度動態標記（Markers）急診燈號與即時量能彈出視窗（Popups）。

* **✅ 全台重度急救責任醫院覆蓋**：已完美串接全台 **59 間**核心重度級急救醫院的數據。
* **✅ 15 分鐘高速全自動更新**：後端排程維持高頻率自動同步，即時監控「等待住院、看診、推床及加護病房」之核心指標。
